1. SpringEduManager - Sistema de Gestión Educativa

Ver Repositorio

Descripción: Aplicación web para la gestión centralizada de alumnos y cursos desarrollada con arquitectura en capas MVC[cite: 3].

Desafío Principal: Configurar un esquema estricto de seguridad con Spring Security para restringir la creación de cursos únicamente a administradores (`ADMIN`) y bloquear accesos no autorizados[cite: 3].

Solución Propuesta: Implementación de autenticación con roles, mapeo ORM mediante Spring Data JPA, vistas dinámicas Thymeleaf y exposición de servicios RESTful[cite: 3].

Métricas de Impacto: 100% de efectividad en el bloqueo de peticiones no autorizadas y precarga de datos H2 en menos de 2 segundos[cite: 3].

Aprendizajes Clave: Manejo de excepciones de seguridad, desacoplamiento de capas y empaquetado autónomo en ejecutable `.jar`[cite: 3].

Justificación de Elección: Proyecto integrador que demuestra el ciclo completo de desarrollo backend moderno[cite: 3].
